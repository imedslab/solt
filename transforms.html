class solt.transforms.Blur(p=0.5, blur_type='g', k_size=3, gaussian_sigma=None, data_indices=None)[source]¶

Transform blurs an image

Parameters:

  • p (float) – Probability of applying this transform,

  • blur_type (str) – Blur type. See allowed blurs in solt.constants

  • k_size (int or tuple) – Kernel sizes of the blur. if int, then sampled from (k_size, k_size). If tuple, then sampled from the whole tuple. All the values here must be odd.

  • data_indices (tuple or None) – Indices of the images within the data container to which this transform needs to be applied. Every element within the tuple must be integer numbers. If None, then the transform will be applied to all the images withing the DataContainer.

  • data_indices (tuple or None) – Indices of the images within the data container to which this transform needs to be applied. Every element within the tuple must be integer numbers. If None, then the transform will be applied to all the images withing the DataContainer.

  • p (float) – Probability of applying this transform.

class solt.transforms.Crop(crop_to=None, crop_mode='c')[source]¶

Center / Random / Corner crop transform.

Object performs center, random or corner cropping depending on the parameters. The center and the four corner crops make the five crops, which are often used for test-time augmentation.

Parameters:

  • crop_to (tuple or int or None) – Size of the crop (width_new, height_new). If int, then a square crop will be made.

  • crop_mode (str) – Crop mode. Can be 'c' - center, 'r' - random, or a corner: 'lt' - left top, 'rt' - right top, 'lb' - left bottom and 'rb' - right bottom.

See also

solt.constants.ALLOWED_CROPS

Notes

To avoid copying, the cropped images, masks and distance maps are views of the input arrays.

class solt.transforms.CutOut(cutout_size=2, n_cuts=1, data_indices=None, p=0.5)[source]¶

Does cutout augmentation.

https://arxiv.org/abs/1708.04552

Parameters:

  • cutout_size (tuple or int or float) – The size of the cutout (width, height). If int or float, then the cutout is a square. int values are in pixels, and float values are fractions of the image size. Each of the width and the height can also be a range (min, max), from which the size of every cutout is sampled, e.g. ((4, 16), (4, 16)). By default, it is 2.

  • n_cuts (int or tuple of int) – Number of cutouts to make. If tuple (min, max), then it is sampled from this range. By default, it is 1.

  • data_indices (tuple or None) – Indices of the images within the data container to which this transform needs to be applied. Every element within the tuple must be integer numbers. If None, then the transform will be applied to all the images withing the DataContainer.

  • p (float) – Probability of applying this transform.

Notes

To avoid copying, the transform modifies the image it receives in place. If the input image must stay unchanged, e.g. because it is cached or augmented several times, use Stream(..., in_place=False) or pass a copy.

class solt.transforms.GridMask(d_range=None, ratio=0.6, rotate=0, mode=None, data_indices=None, p=0.5)[source]¶

Performs a GridMask augmentation.

https://arxiv.org/abs/2001.04086

The image is split into units of d x d pixels. Every unit has a kept band of width l = ceil(d * ratio) along its top and left sides, which forms a grid of kept lines, and the remaining square of side d - l is dropped (set to 0). Without rotation, approximately (1 - ratio) ** 2 of the image is dropped (exactly ((d - l) / d) ** 2, up to the incomplete units at the borders), i.e. ratio is the ratio r of the paper, and the keep ratio is 1 - (1 - ratio) ** 2. The grid has a random offset, and the same mask is applied to all the channels of the image.

Parameters:

  • d_range (tuple or None) – The range of the unit size d. The d is chosen between (d_range[0], d_range[1]), both inclusive. If None, then the d is chosen between (1, 10).

  • ratio (float) – The ratio of the width of the kept lines to the unit size d, between 0 and 1. The dropped squares have the side d - ceil(d * ratio), i.e. 0 drops the whole image and 1 keeps it.

  • rotate (int or tuple or None) – If int, then the angle (in degrees) of grid mask rotation is between (-rotate, rotate). If tuple, then the angle of grid mask rotation is between (rotate[0], rotate[1]). The integer angle is chosen with both ends inclusive. If 0 or None, then the mask is not rotated.

  • mode (str or None) – GridMask mode. If 'crop' or 'none' (default, used when mode is None), then the default GridMask is applied: the squares are dropped, and the grid lines are kept. If 'reverse', the inversed GridMask is applied: only the squares are kept, and the grid lines are dropped, i.e. exactly the complement of the default mode is dropped. 'reserve' is an alias of 'reverse', kept for backward compatibility.

  • data_indices (tuple or None) – Indices of the images within the data container to which this transform needs to be applied. Every element within the tuple must be integer numbers. If None, then the transform will be applied to all the images withing the DataContainer.

  • p (float) – Probability of applying this transform.

Notes

To avoid copying, the transform modifies the image it receives in place. If the input image must stay unchanged, e.g. because it is cached or augmented several times, use Stream(..., in_place=False) or pass a copy.

serializable_name = 'gridmask'¶

class solt.transforms.Pad(pad_to=None, padding=None)[source]¶

Transformation, which pads the input to a given size

Parameters:

  • pad_to (tuple or int or None) –

    Target size (width_new, height_new). The padding is computed using the following equations:

    left_pad = (pad_to[0] - w) // 2 right_pad = (pad_to[0] - w) // 2 + (pad_to[0] - w) % 2 top_pad = (pad_to[1] - h) // 2 bottom_pad = (pad_to[1] - h) // 2 + (pad_to[1] - h) % 2

  • padding (str) – Padding type.
