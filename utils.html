solt.utils.distance_map_border(border_mode, settings)[source]¶

Returns the OpenCV border mode and value to pad a distance map with.

Zero padding would create a false object boundary in a distance map. Therefore, for the zero padding mode, a distance map is padded with its fill value if it is set, and with its edge values otherwise.

Parameters:

  • border_mode (int) – OpenCV border mode, which the transform uses for this item.

  • settings (dict) – Item-wise settings of the distance map.

Returns:

out – OpenCV border mode and value.

Return type:

solt.utils.distance_map_handler(method)[source]¶

Decorator for the _apply_distance_map methods of transforms.

It makes sure that the result has the same dtype and the same number of dimensions as the input:

  • float16 distance maps are processed in float32, since most of OpenCV does not support float16.

  • Distance maps with more than 4 channels are processed in groups of at most 4 channels, since some OpenCV operations (e.g. bicubic interpolation or a constant fill value) only support up to 4 channels.

Parameters:

solt.utils.mask_to_sdf(mask, max_distance=None, dtype=<class 'numpy.float32'>)[source]¶

Computes the signed distance field (SDF) of a binary mask.

The distances are in pixels: negative inside of the objects and positive outside. The pixels next to a boundary have the distance of 1 (or -1), i.e. the boundary (the zero level) lies half way between the inside and the outside pixels. The result can be augmented as a distance map ('D') in a DataContainer.

Parameters:

  • mask (numpy.ndarray) – Binary mask HxW, or a multi-label mask HxWxC, for which the SDF of every channel is computed. Non-zero values belong to the objects.

  • max_distance (int or float or None) – If set, the distances are clipped to [-max_distance, max_distance] (truncated SDF).

  • dtype (numpy.dtype) – Floating point type of the result, e.g. numpy.float16.

Returns:

out – SDF of the same shape as the mask. If a mask (channel) has no boundary, i.e. it is empty or full, all of its distances are equal to the image diagonal (or to max_distance if it is set): positive for an empty mask and negative for a full one.

Return type:

numpy.ndarray

solt.utils.validate_parameter(parameter, allowed_modes, default_value, basic_type=<class 'str'>, heritable=True)[source]¶

Validates the parameter and wraps it into a tuple with the inheritance option (if parameter is not a tuple already). In this case the parameter will become a tuple (parameter, ‘inherit’), which will indicate that the stream settings will override this parameter. In case if the parameter is already a tuple specified as parameter=(value, ‘strict’), then the parameter will not be overrided.

Parameters:

  • parameter (object) – The value of the parameter

  • allowed_modes (dict or set) – Allowed values for the parameter

  • default_value (object) – Default value to substitute if the parameter is None

  • basic_type (type) – Type of the parameter.

  • heritable (bool) – Whether to check for heretability option.

Returns:

out – New parameter value wrapped into a tuple.

Return type:

tuple
